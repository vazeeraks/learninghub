SQL

SQL (Structured Query Language) is the standard language for managing and retrieving data within relational database management systems (RDBMS).

SQL lets you create, read, update and delete data stored in tables. It is used by developers, data analysts and database administrators worldwide.

Knowledge of SQL is essential for backend development, data science, and business intelligence roles.
